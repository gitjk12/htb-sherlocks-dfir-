# HTB Sherlock: Unit42 (Very Easy)

**Scenario:** Sysmon log from a Windows host (`DESKTOP-887GK2L`, user `CyberJunkie`) infected by a trojanized UltraVNC installer. Investigated in Splunk.

## Tools
- **Splunk:** searched the Sysmon events by Event ID and read the fields.
- **evtx to JSON conversion:** Splunk could not decode the raw `.evtx` on upload, so I converted it to JSON lines (169 events) and uploaded it as sourcetype `unit42`.

| Search | Used for |
|---|---|
| `EventID=11` (FileCreate) | Tasks 1, 5 |
| `EventID=1` (ProcessCreate) | Task 2 |
| `EventID=22` (DNSQuery) | Tasks 3, 6 |
| `EventID=2` (FileCreateTime changed) | Task 4 |
| `EventID=3` (NetworkConnect) | Task 7 |
| `EventID=5` (ProcessTerminate) | Task 8 |

## Summary
CyberJunkie downloaded `Preventivo24.02.14.exe.exe` from Dropbox (Firefox looked up Dropbox domains at 03:41:25 and 03:41:43) and ran it from his Downloads folder at 03:41:56. The file posed as an invoice, but it was an installer for a program called "Photo and vn".

It unpacked its files into a folder under `AppData\Roaming`, including `main1.msi` and `once.cmd`, then started `msiexec` to install `main1.msi`, which wrote more files to disk. It also changed the creation times of the files it dropped, including a PDF (backdated to 2024-01-14 08:10:06), so they would blend in with older files (time-stomping).

It connected to `www.example.com` (`93.184.216.34`), most likely to check that the internet was reachable, and the process terminated itself at 03:41:58, about two seconds after it started. According to the scenario, the end result was a backdoored UltraVNC left on the machine.

## Additional Findings
Extra Splunk searches to fill in what the tasks did not ask about. Splunk's `_time` is when the event was written; the `UtcTime` field inside an event can be up to about 2 seconds earlier.

### Processes started (`EventID=1`)
Only six processes were created. Firefox's `pingsender.exe` is normal telemetry. The rest is the malicious exe (run by `explorer.exe` at 03:41:56) and a chain of `msiexec.exe` processes, one of which installs `main1.msi` (its parent is the exe). None of the dropped programs (`taskhost.exe`, `viewer.exe`) was ever started in this log.

```
source="C:\\unit42_events.jsonl" host="LAFRANCE" sourcetype="unit42" EventID=1
| table _time Image CommandLine ParentImage User | sort _time
```

![extra1-process-timeline](shots/extra1-process-timeline.png)

### Files created, by process (`EventID=11`, 56 events)
- **Firefox** wrote the malicious exe into Downloads, including a `Zone.Identifier` file, which marks it as downloaded from the internet.
- **The exe** wrote six files to its AppData staging folder: `c.cmd`, `cmmc.cmd`, `on.cmd`, `once.cmd`, `taskhost.exe` and `viewer.exe`.
- **`msiexec`** wrote the same six names to `C:\Games\`, plus its own installer temp files under `C:\Windows\Installer` and `C:\Windows\Temp`.
- **`mmc.exe`** saved the Sysmon log to the Desktop (most likely the analyst exporting the evidence).
- **`svchost.exe`** wrote Prefetch files.

```
source="C:\\unit42_events.jsonl" host="LAFRANCE" sourcetype="unit42" EventID=11
| stats values(TargetFilename) by Image
```

![extra2-files-created-by-process](shots/extra2-files-created-by-process.png)

### Preventivo vs msiexec
- **Preventivo** carried the files inside itself and unpacked them into the AppData staging folder. Nothing was downloaded after it ran: the only network connection in the log is the one to `www.example.com`.
- It then started one `msiexec` (`/i main1.msi`), which **installed** the files into `C:\Games\`.
- The other `msiexec` processes (`/V` and two `-Embedding`) are Windows Installer's own helpers for that same install.

### Time-stomping (`EventID=2`, 16 files)
The malware backdated 16 files, not just the PDF. Most were set to 2024-01-10 18:12:26 to 18:12:27, the PDF to 2024-01-14 08:10:06, and `main1.msi` to 2024-01-14 08:14:23. Their real creation time was 2024-02-14 03:41:57 to 03:41:58. The list includes the scripts, `taskhost.exe`, `viewer.exe` and the UltraVNC-related files (`UltraVNC.ini`, `vnchooks.dll`, the `UVncVirtualDisplay` driver files).

```
source="C:\\unit42_events.jsonl" host="LAFRANCE" sourcetype="unit42" EventID=2
| table _time TargetFilename CreationUtcTime PreviousCreationUtcTime
```

![extra3-timestomped-files](shots/extra3-timestomped-files.png)
